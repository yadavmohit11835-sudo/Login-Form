# 🔐 ModernAuth — Glassmorphic Login & Register Portal

A futuristic, ultra-modern, and fully responsive **Sign In & Sign Up Portal** built with **HTML5**, **CSS3 (Glassmorphism & Variables)**, and **Vanilla JavaScript**. Zero external framework dependencies, ultra-fast loading, and ready for deployment on GitHub Pages.

---

## ✨ Features & Highlights

- 💎 **Glassmorphic UI Design:** Frosted glass aesthetic with backdrop blur (`backdrop-filter: blur(24px)`), ambient floating glow orbs, and subtle shimmer accents.
- 🌓 **Dark & Light Mode:** Seamless theme toggler with local persistence (`localStorage`) and system preference fallback.
- 🔄 **Sliding Tab Switcher:** Fluid horizontal animation between **Sign In** and **Create Account** forms without page reloads.
- 👁️ **Interactive Password Eye Toggle:** Reveal and hide password toggles for secure and convenient user input.
- 📊 **Real-time Password Strength Meter:** Dynamic color-coded security indicator (Too Weak, Fair, Good, Strong & Secure) measuring length, casing, numbers, and symbols.
- 🛡️ **Client-Side Form Validation:**
  - Real-time format checks for Email addresses.
  - Password matching validation on registration.
  - Interactive micro-animations (card shake on error, glowing focus rings).
- 🔑 **Forgot Password Dialog:** Beautiful modal pop-over with smooth backdrop blur and simulated reset link delivery.
- 🌐 **Social Sign-In Buttons:** Clean SVG-supported buttons for Google and GitHub authentication.
- 🔔 **Custom Animated Toasts:** Built-in floating notifications with automatic dismissal for feedback (Success, Info, Error).
- 📱 **100% Mobile Responsive:** Optimized across mobile screens, tablets, laptops, and ultra-wide desktops.

## 🛠️ How to Update Your GitHub Repository

To push these new files to your GitHub repository (**[Login-Form](https://github.com/yadavmohit11835-sudo/Login-Form)**):

### Method 1: Using GitHub Web (Easiest)
1. Go to your repository: [github.com/yadavmohit11835-sudo/Login-Form](https://github.com/yadavmohit11835-sudo/Login-Form)
2. Click **Add file** -> **Upload files**.
3. Drag and drop all 4 files from this folder (`index.html`, `style.css`, `script.js`, `README.md`).
4. Click **Commit changes**.

### Method 2: Enable GitHub Pages (To Make it Live Online for Free)
1. In your GitHub repository, click on **Settings** (top menu).
2. On the left sidebar, click **Pages**.
3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
4. Within 1-2 minutes, your website will be live at:
   `https://yadavmohit11835-sudo.github.io/Login-Form/`
